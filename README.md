## A Remote Access Trojan (RAT) is a type of malware that secretly gives an attacker full control over a victim’s computer from a remote location.

It typically allows the attacker to:

Monitor activity (e.g., via keystrokes or screenshots)

Access files and programs

Install more malware

Control the system as if they were the user

 It’s often spread through phishing emails, fake software downloads, or exploits, and is illegal to use without permission.
